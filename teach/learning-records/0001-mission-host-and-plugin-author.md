# 起点：宿主与插件两侧同时学

用户确立任务（mission）：既要写宿主（把 Cordis 内嵌进自己的产品），也要写插件（提供并消费服务）。此前他已经跑过 `bash conformance/run.sh`（早期版本的验收结果，当前范围见生命周期验收文档）、用 CLI 完成 `pack` + `run` 的真实调用，并读过 `examples/plugins/counter` 与 `examples/basic-host` 的流程，因此“安装→选择→启用→调用”这条主干不需要再教。

**Implications**：可以从边界语义切入，而不是从 API 目录切入。首轮两个问题（跨进程类型安全、插件依赖插件）正好落在两条最容易出错的接缝上，适合作为 0001/0002 两节课；后续优先级见 `NOTES.md` 的候选课程。

**Evidence**：用户在会话中明确给出目标“写宿主，也写插件”，并主动要求“来点人能看得懂的例子”；此前的 CLI 实测输出来自本仓库当前修订。
