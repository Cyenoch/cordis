类型边界速查

Cordis 跨进程只传 JSON。类型安全不是“两边类型相同”，而是“错配一定在某个可见的闸门失败”。

四道闸门

闸门何时触发拦住什么证据
生成期 schema.Compile / cordis generate / 安装时校验 configSchema schema 自身错误（$ref、allOf、未声明 required、非法 pattern、重复 enum）、Go 名称冲突、超范围常量。生成代码内置严格 Marshal/Unmarshal，编解码两侧都校验。 docs/contracts.md、schema/
注册期 sdk.Provide[In,Out] 调 contract.CheckDataType 指针、interface、func、chan、unsafe.Pointer、递归类型；非 string 的 map key；裸 int64/uint64；字段 JSON tag 非法。 contract/data.go、sdk/typed.go
编解码期 contract.Decode/DecodeData/Encode，每次跨边界 未知字段、重复 key、尾随数据、非法 UTF-8、深度 > 32、数组 > 10,000、非有限浮点。 contract/json.go
业务期 Handler 返回错误 显式错误码：invalid_message、denied、timeout、canceled、reentrant_call、plugin_failed 等；不把失败转成零值。 contract/types.go（Code）

注册期：允许与禁止

Go 类型结果原因 / 替代
string bool int int8/16/32 uint…32 float32/64允许JSON 原生可表示。
int64 uint64拒绝报错 requires an explicit decimal-string codec；用 format:"int64" 的字符串字段，避免 JSON number 的精度歧义。
[]T、[N]T允许元素递归检查；[]byte 走 base64 codec。
map[string]T允许key 必须是 string。
map[int]T拒绝service map keys must be strings。
*T、interface{}、func、chan、unsafe.Pointer拒绝nonserializable service type；可选值用 schema.Optional[T]，null 用 schema.Nullable[T]。
递归结构（A 含 A）拒绝recursive service type；改成 id 引用或分层类型。
实现 DataType 或双向 json.Marshaler/Unmarshaler允许自定义 codec 自己负责 wire 表示（如 schema.Nullable）。

编解码期：严格 JSON 规则

规则行为
未知字段拒绝（DisallowUnknownFields）——拼错字段名不会静默变成零值。
重复 key拒绝——不会“后者覆盖前者”。
尾随数据拒绝（trailing JSON data）。
UTF-8非法字节直接拒绝。
嵌套 / 数组规模深度上限 32，单数组上限 10,000；持久化宿主 envelope 用 DecodeWithLimits 显式指定自己的上限，不用默认值兜底。
数字必须可表示为有限 float64；生成器里 number 换成 json.Number 保留词法值，避免重编码舍入。
缺失 vs null不等价；需要 null 必须在 schema 里显式 nullable:true。

生成契约的工作流

  1. 写 *.schema.json（schema: "cordis-go.contract/v1"，服务名 + major/minor + 方法 + request/response 子 schema）。
  2. cordis generate -package echo echo.schema.json > echo/echo.go（或 schema.Generate(w, "echo", def)）。
  3. 插件侧：echo.RegisterExampleEchoServer(scope, impl)；宿主/消费者侧：echo.NewExampleEchoClient(scope).Echo(ctx, req)。
  4. 把生成文件当作两边共享的契约包：字段、可选性、int64、base64、union 都由它约束，而不是各自手写 struct 再靠人记。
关键取舍

手写 struct + contract.Decode 也能用，代价是契约只存在于两边的代码里：改名、加字段、改可选性都不会被任何闸门发现，只会在运行时以未知字段或零值出现。生成包把这份契约变成可编译、可校验的产物。

错误码速查

码含义典型触发
invalid_message输入不合法未知操作、坏 JSON、越界值
incompatible协议/版本不兼容major 不同、无共同 minor
not_ready尚未可用启动未完成、实例已被替换
denied未授权能力未声明/未授予、scope 校验失败
timeout / canceled期限/取消调用等待超时、context 取消
reentrant_call重入初始化里等自己的子实例、middleware 二次 next、依赖环
plugin_failed / internal插件/框架内部失败Start 返回错误、协议错误
