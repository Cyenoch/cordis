术语表

课程里所有叫法以本页为准。每个词给出对应的代码符号，避免“概念名”和“API 名”各说一套。

术语代码符号一句话定义
包 / Packagepackagehost.Package、contract.Manifest一份不可变的 ZIP：manifest + 本平台产物；身份是 ID + 严格 SemVer + digest。
Manifestplugin.json声明定义、服务、版本、Runtime、依赖、能力、配置 schema 的 JSON；打包后参与摘要计算。
CatalogOptions.Directory宿主持久目录：装了哪些包、选中哪个版本、entry 配置、信任证明。安装不改变选择。
选择 / SelectHost.Select把某个已安装版本设为该包 ID 的当前版本；新装的版本不会自动生效。
Entrycontract.Entry宿主声明“我要跑这个包的这个定义，用这份配置”的记录，ID 在宿主内唯一。
Activationcontract.Identity.Activation一次真实启动；每次启动新 ID，旧 ID 的权限一律失效。一个 entry 可有多次激活。
Scopecontract.Scope一个 activation 的能力面：身份、配置、注册服务/订阅、调用、Defer 清理。插件只拿到它。
Definitioncontract.Definition包内一个可独立实例化的启动单元（ID + Requires + Provides + Start）；一个产物可含多个。
Servicecontract.Serviceprovider 发布的服务声明：名字 + major（+ minor）。绑定键是 name@major。
Requirementcontract.Requirementconsumer 的依赖声明：名字 + major + minor 闭区间 [MinMinor, MaxMinor]。
Capabilitycontract.Capability宿主能力（宿主实现、插件调用）；manifest 声明，宿主 Authorize 授权，Broker 处理。
RealmHost.ConfigureRealm可见性作用域：服务沿 realm 向后代可见；隔离键不继承父 realm。
WaitingForcontract.Status.WaitingFor实例没到 active 的原因列表，元素是 name@major 或 parent:<id>。
Diagnosticcontract.Status.Diagnostics非致命问题（可选包缺失、版本不兼容）；不阻止启动，但要能被看到。
PreflightStore.Preflight启用前的包层检查：必需依赖是否已被选择、版本区间、依赖环；可选依赖只产诊断。
SnapshotStore.Snapshot把选中包复制到本次执行私有目录，重新校验完整性与信任后才交给 Runtime。
Digestpackagehost.Package.Ref.Digest内容身份（路径+大小+SHA-256 的规范序），开发期授权与签名都签它。
Child instancecontract.CreateChild / Entry.Parent子实例：作者在 Start 内创建（随 activation 回收）或宿主用 Parent 持久编排。
SubtreeHost.Disable停用父 entry 会持久停用整棵子树；Restore 不会把它们悄悄拉起来。
用法约定

课程里说「服务依赖」指 Requires/Provides；说「包依赖」指 manifest 的 dependencies；说「父子」指 entry 所有权。三者互不替代，混用会产生不同层级的错误。
