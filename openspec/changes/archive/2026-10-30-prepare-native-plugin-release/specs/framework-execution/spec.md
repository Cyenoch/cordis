# Spec Delta

## ADDED Requirements

### Requirement: native 运行资源位置
native 运行时 SHALL 提供由宿主设置的绝对包快照位置，使插件能读取已声明资源；该位置对应本 activation 的已验证包内容，生命周期不短于其运行和清理。运行时保留私有可写工作目录，资源位置不依赖调用者 cwd。显式环境不得覆盖宿主保留的资源位置变量；该路径不代表操作系统权限隔离或可持久化业务数据目录。

#### Scenario: 从安装快照读取资源
- **WHEN** 原作者目录已删除或修改，插件从安装包启动并读取声明的模板资源
- **THEN** 获取本 activation 快照中的已验证内容，不读回作者目录；两个 activation 各自使用其快照

#### Scenario: 资源环境冲突
- **WHEN** 宿主显式环境试图覆盖保留的资源位置变量
- **THEN** 在创建插件进程前明确拒绝，不静默使用错误目录
