# Spec Delta

## Purpose

让宿主维护者从实例身份追踪启动、运行、退役和包管理结果，在重开后仍能解释最近一次失败。诊断复用运行记录和宿主日志出口，不承担业务日志存储、自动恢复或合规审计职责。

## ADDED Requirements

### Requirement: 归属明确的运行诊断
框架 SHALL 提供可选的结构化日志出口，记录状态转换、启动耗时、调用失败和包管理结果。记录包含发生时间、操作、结果及当时可用的包摘要、entry、activation、父激活和错误分类。框架 MUST NOT 默认记录配置、调用输入输出、环境变量或插件原始 stderr；用户代码返回的错误文本不承诺自动脱敏。

#### Scenario: 同包实例故障定位
- **WHEN** 同一包运行两个实例，其中一个服务调用失败后进程退出
- **THEN** 调用失败和退出记录分别带该实例的 activation，另一实例不被误标失败；记录不包含请求及响应正文

#### Scenario: 发布之前启动失败
- **WHEN** native 初始化失败，尚未达到 Active
- **THEN** 记录初始化阶段、失败分类及从启动到失败的耗时，不输出成功发布记录

### Requirement: 退出结果与有限历史
native 退出结果 SHALL 区分请求停止、意外退出、协议失败、强制终止和宿主中断；exit code、signal 仅在平台实际提供时填写。现有有界运行历史 SHALL 保留终态分类、可用的启动耗时和独立清理结果，只保存固定结构的分类及数值，不持久保存任意错误文本、原始 stderr 或栈；具体错误链通过当次 API 和可选日志提供。宿主异常消失后未完成记录仍标记 interrupted，不猜测崩溃原因。

#### Scenario: 意外零退出与正常停止
- **WHEN** 一个插件未收到停止请求便 exit 0，另一个在正常停用后退出
- **THEN** 前者记为意外退出并进入失败，后者记为请求停止；不能只根据退出码将两者都记为成功

#### Scenario: 重开检查失败记录
- **WHEN** native 因非零退出结束，维护者关闭并重新打开 Store
- **THEN** 最近记录仍能返回失败分类及已知退出码；历史沿用现有容量限制，不无限累积

#### Scenario: 生命周期成功但清理失败
- **WHEN** 插件正常停止但资源清理报错，activation 已经释放
- **THEN** 终态保留对应 activation 身份，停止原因和清理错误分别可见，不因进程退出成功而抹掉清理错误；interrupted 的恢复时间不冒充真实崩溃时间

#### Scenario: 大错误文本不破坏重开
- **WHEN** 多次失败返回较大的错误文本，并积累到终态历史容量
- **THEN** 当次返回值和可选日志仍提供具体错误，持久历史仅保留固定结构结果并符合既有文件字节预算，Store 能正常重开

### Requirement: 显式插件输出与栈采集
原始 stderr 转发 SHALL 由宿主显式启用，并标注来源身份与截断状态；沿用现有每激活字节预算，超额继续排空管道。框架捕获的 builtin panic SHALL 保留错误类别，栈仅在显式诊断选项下采集输出；对 native 仅转发现实存在的栈，不承诺从被强杀进程恢复栈。

#### Scenario: 插件大量输出
- **WHEN** 已启用输出转发的插件超过预算后继续写 stderr
- **THEN** 宿主报告该 activation 的截断，继续排空；其他实例的来源不混淆，插件不会因停止读取管道而挂死

#### Scenario: 默认不泄漏原始诊断
- **WHEN** 插件向 stderr 写入敏感文本或 builtin 发生 panic，但未启用原始诊断
- **THEN** 普通状态和运行历史不嵌入 stderr 或栈；仍能获得失败分类

### Requirement: 诊断不改变业务提交结果
日志出口 SHALL 在内部状态锁外调用；启用或禁用日志 MUST NOT 改变生命周期和包提交语义。包操作记录 SHALL 区分拒绝、已提交、已提交但后续同步失败；日志只是诊断，不承诺事务性、安全审计完整性或自动重试。宿主提供的日志处理器遵守及时返回、不重入管理调用的契约。

#### Scenario: 提交后同步报错
- **WHEN** 包选择已经提交但持久同步返回错误
- **THEN** 操作仍返回提交后错误，诊断表明提交已发生，不将其记为未改变状态或自行再执行一次

#### Scenario: 无日志接收者
- **WHEN** 宿主未配置日志出口，发生调用失败
- **THEN** 原调用仍返回原错误，相关终态仍可查询，不依赖后台日志消费者才能结束
