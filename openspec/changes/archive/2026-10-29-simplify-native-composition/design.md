# Design

## Context

见 proposal.md。原 Host 将组合状态机与 access 的多个注册表耦合，协议、构建、示例和验收又同时维护两类产物。本次直接删除未发布 API，不保留兼容包装。

## Goals / Non-Goals

目标是保留实例、依赖、服务、事件、父子资源和 native 插件开发的完整闭环。应用授权、任务、数据存储、脱敏、贡献和专属协议不再属于库。

## Decisions

- `contract` 只保留组合与标准会话；`internal/core` 协调激活，`sdk` 实现进程端，`runtime/native` 管理进程。根 Host 只连接核心与 `packagehost`。
- 删除 access、WASI worker、wazero、宿主协议注入、全局子定义表和公开资源组。资源组的 SDK 清理机制移入内部包，作者只使用 Defer。
- 每个 Host 使用单一服务注册表，删除人工 realm 树与路由参数。需要彼此隔离的插件集合使用独立 Host；父子实例保留真实所有权。
- 保留 Update 的校验、revision 和迟到结果隔离，因为并发更新会发生。失败可提交 Update 再启动，不再叠加 Retry 或自动 Supervise。删除级联计划及确认回调；依赖冲突由调用者通过显式停用解决。
- builtin 子定义放进父 Definition.Children，外部定义来自同一包。CreateChild 仍在父发布后启动子实例；登记与父退役的竞争继续由激活身份检查保护。
- 进程作者只用 sdk.Run；测试保留 RunTransport，二者分别控制系统进程和显式流。删除 Main、Serve 和定义数量相关的多套公开函数。
- 项目未发布，直接修改 schema、Manifest、会话和持久目录格式，删除旧应用字段与 runtime 分支，不增加旧格式解析或迁移。签名算法保留，不为接口删除引入新签名版本。
- 签名、解包路径、消息预算、取消、调用环、清理错误和非合作代码阻塞均有具体失败模式，继续保留。拒绝通过删掉这些检查换取表面行数下降。

- 文档直接对应当前检出，构建变量读取本地 go.mod；删除每页历史提交映射、远程发行版查询和相应同步工具。保留可执行教程与生产链接检查。
- 子定义按请求 ID 解析；重复 ID 返回 Conflict，不按切片顺序猜测。嵌套子定义使用相同解析路径。

## Risks / Trade-offs

- 删除公开 API → 同步修改全部调用者、生成模板、文档及测试，独立审查边界。
- 移除 realm → 同 Host 同 service key 的重复 provider 返回 Conflict；不同父实例不构成隔离域。
- 只支持 native → 不提供权限沙箱，运行由调用者决定。
- 未发布格式直接收敛 → 工具、schema 和 fixtures 一次性更新，不维护双轨格式。
- 清理及并发变更 → 使用 race、依赖链清理和真实 native 进程验收验证，未经执行的平台不宣称通过。

## Migration Plan

先更新变更规格，再改公开契约与实现，随后迁移示例、验收、中文文档与主规格。删除原有应用层和 WASI 专属测试，保留并迁移当前组合、取消、协议与完整性契约测试。历史设计记录不再列出具体应用名称，原文版本可通过 Git 查阅。
