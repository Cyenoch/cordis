# Spec Delta

## ADDED Requirements

### Requirement: 无执行的实例意图编辑
持久存储 SHALL 支持不创建 activation 的 entry 启用/配置更新、子树停用及已停用叶 entry 的意图删除。保存前校验选中包、definition、配置、父子图和隔离声明；停用父 entry SHALL 原子停用其持久后代，不删除业务数据。离线只用目录独占权确认无运行中 Host，不把历史 running 状态当成进程存活证据，也不绕过现有反向依赖约束。

#### Scenario: 非法离线配置
- **WHEN** 用户保存不符合当前选中 definition 的配置
- **THEN** 返回字段错误，原配置和 enabled 意图不变，没有插件被执行

#### Scenario: 停用持久父子树
- **WHEN** 离线停用一个包含多级持久子 entry 的父 entry
- **THEN** 所有后代的 enabled 意图在同一次提交中关闭，下一次 Restore 不运行它们，兄弟树不变

#### Scenario: 反向依赖拒绝
- **WHEN** 离线尝试卸载其他启用 entry 仍依赖的选中包
- **THEN** 操作被拒绝并指出冲突，不因没有当前进程而跳过启用意图的依赖检查

#### Scenario: 删除意图遵守父子图
- **WHEN** 离线尝试删除仍启用的 entry 或仍有持久子项的父 entry
- **THEN** 操作被拒绝且 catalog 不变；停用并按叶到根顺序删除后可以继续版本选择，不删除已安装包及业务数据

### Requirement: 替换阶段和显式回退
包替换 SHALL 在停止旧实例之前完成已有完整性、信任、平台、包依赖和配置预检，预检失败保留旧实例。旧实例退役后 SHALL 遵守消费者先清理及在途工作排空；新代码初始化失败保留可观察失败状态。宿主可显式再次选择已安装旧包完成代码回退，MUST NOT 声称业务状态回滚或自动重放调用；旧运行句柄不得控制重建实例。

#### Scenario: 新版本无法启动
- **WHEN** 新包预检通过但初始化失败，宿主随后显式 Replace 回已安装旧包
- **THEN** 新版本失败阶段和两个版本摘要可诊断，旧包重新建立 activation；仍需通过当前配置/信任校验，不恢复旧进程内存或撤销新版本副作用

#### Scenario: 排空尚未完成
- **WHEN** 替换等待旧实例清理时超时
- **THEN** 返回清理未完成，保持真实状态，不提前使用相同资源启动新实例，不声称无缝切换

### Requirement: 开发循环不得改变正式包身份
正式安装 SHALL 继续拒绝同一包 ID/版本的不同内容，不允许开发命令开启 Store 全局覆盖模式。开发候选的隔离目录及精确摘要许可 SHALL 仅用于本次开发会话，退出后不向生产目录或信任文件写入授权。

#### Scenario: 同版本不同内容
- **WHEN** 开发者多次修改源码而不修改发布版本
- **THEN** 开发循环可在各自独立候选目录验证这些产物；将不同摘要安装到同一正式 Store 时仍报冲突
