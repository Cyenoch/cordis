# Spec Delta

## ADDED Requirements

### Requirement: 显式发行文件集合
作者声明及机器 Manifest SHALL 支持显式运行资源文件清单。发行包 SHALL 只包含机器 Manifest、全部声明 native 产物、列出的资源及完整性/签名元数据。未列出的文件不得因位于作者目录而进入包；资源只接受包内规范相对普通文件路径，不支持目录、glob、链接、重复路径或元数据覆盖。缺少文件 SHALL 失败，不能静默省略。

#### Scenario: 开发目录有非发行文件
- **WHEN** 作者目录含源码、开发配置、日志和未声明的私钥，构建后打包
- **THEN** ZIP 只含允许的发行集合，未声明内容不出现在 ZIP 或完整性表

#### Scenario: 显式资源可用
- **WHEN** 作者声明模板文件作为资源并构建、打包、签名和安装
- **THEN** native 从运行快照读取到原文件内容，其摘要受签名保护

#### Scenario: 非法或缺失资源
- **WHEN** 资源清单含目录、链接、重复路径、越界路径、保留元数据路径或不存在的文件
- **THEN** 打包报出具体路径，已有输出 archive 不变

### Requirement: 精简发行不削弱构建校验
从作者声明打包时 SHALL 在同一私有输入快照内验证声明、生成代码、SDK 信息与所有声明目标的构建证据，再生成发行内容。校验用输入不必成为发行文件。构建证据缺失、过期或产物漂移 MUST 拒绝；取消或失败不得发布部分 archive。机器 Manifest 输入仍按其声明的产物和资源打包，不伪造作者构建证据。

#### Scenario: 生成代码不发布但仍需验证
- **WHEN** 生成代码已被修改或缺失，且不在发行资源中
- **THEN** Pack 仍失败，不能因生成文件不进入 ZIP 而跳过检查

#### Scenario: 部分平台未构建
- **WHEN** Manifest 声明两个平台，但构建证据只覆盖一个或其中一个产物摘要不符
- **THEN** Pack 失败，旧 archive 保留

#### Scenario: 不相关目录不参与打包
- **WHEN** 作者目录有未声明的大目录或无关链接
- **THEN** 它们不作为发行或校验输入，不因其大小或内容导致本包打包失败；声明文件仍遵守路径和配额约束

### Requirement: 可检查的发行内容
inspect SHALL 输出验证过的发行文件清单，每项包含规范路径、大小和内容摘要，顺序稳定；包摘要继续使用现有签名域与算法。清单不代表发布者已被信任，生产安装仍要求显式信任。

#### Scenario: 检查已签名包
- **WHEN** 用户 inspect 一个合法签名包
- **THEN** 可以看到实际内容文件与摘要，不读取或显示私钥，不将签名存在等同于宿主授权

#### Scenario: 检查篡改包
- **WHEN** ZIP 文件内容与完整性表不符
- **THEN** inspect 失败，不返回看似有效的文件清单
